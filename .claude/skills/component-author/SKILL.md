# Component author

Use this for an assigned component, after intake and deconfliction. It complements the existing design-intake workflow. The coordinator remains the integration owner.

Prepare the handoff with `node .claude/skills/component-author/prepare.mjs <wave-file> <slug> <output-dir> <export-name> <release> <reference-directory>`. It reuses the current contract and one existing reference, and writes a prompt plus three starter files. Preparation makes no model calls and never changes registry files. The coordinator places the starters only in an empty assigned component directory before dispatch.

The author receives the exact three destination files, export name, behavior brief, palette contract and one preloaded reference. Start implementing from that packet. Read a specific runtime file only when its exact API is missing. Do not rediscover the repository, historical plans, catalog, audit reports or verification implementation. Do not run mechanical checks in the author session. Return the source for native checks instead of exploring a denied command.

Finish after a working core, thin wrapper and complete metadata. Report actual files and any unresolved behavior. A missing API or denied action is a handoff issue, not permission to expand scope or change access.

The coordinator runs scoped lint, types, generation and the existing targeted browser verifier, inspects captures, and repairs concrete failures. Only the coordinator updates aggregate exports and performs Git operations. Reuse the existing deconfliction and brief helpers; do not introduce parallel global generation or persistent hooks.

Use isolated worktrees and disjoint component directories. Limit the current author pool to five, or fewer when requested. Respect the owner's selected model and effort, current billing authorization and pause requests. Never substitute models or enable paid continuation. Native coordination should handle preparation, receipts, queue state and checks. Do not spend author sessions on acknowledgments, broad discovery, duplicate review or work superseded by an unresolved selection.

Record elapsed time to the first source write and first successful render, read/write tool counts, files produced and actual checks. A small prompt is insufficient if the task asks the author to discover everything. Hold queued dispatch when output stalls; preserve sessions and drafts before an authorized stop. Do not restart a paused author or duplicate an active session automatically.
