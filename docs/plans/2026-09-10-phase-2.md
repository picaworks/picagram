# Phase 2: shared runtime, interactive contract, and wave 3

Date: 2026-09-10. Status: approved, in progress.

## Why

Waves 1 and 2 delivered 27 ASCII, text-mode, dither, and effects components on a contract that allowed only scalar props, no events, and no children. The direction widened:
- the breadth of a full component catalog, with a simpler taxonomy and many variants per category;
- charts and shaders as priorities, plus immersive pieces, kanban boards, and React hooks.

Rish chose:
- the house style by default, with palette props so any brand fits;
- an in-house WebGL2 runtime, with a separate evaluation of Vercel's vgpu;
- a wave 3 covering shaders and charts, sections, and controls.

## Decisions

Recorded in `docs/decisions/0004` through `0007`.
- **The palette.** Four CSS custom properties are the source of truth, and a typed `palette` prop writes them onto a host.
- **Budgets per category.** 6 KB for the ASCII-first categories and motion, 8 KB for ui, data, shaders, and immersive, and 16 KB for sections.
- **vgpu is evaluated, not adopted.** It is WebGPU only, about 25 KB for one effect, and an npm dependency. `lib/gl.ts` is about 1 KB.
- **New categories:** sections, ui, data, shaders, motion, and immersive.

## Work

1. **Contract.**
   - JSON props, events with controlled state, children and host ownership, and the palette.
   - `lib/gl.ts`, composition, and per-category budgets.
2. **Shared helpers.** These replace code that the survey of the 27 cores found copied between components:
   - image loading and the failure note;
   - canvas setup;
   - seed hashing;
   - ordered dithering;
   - fitting;
   - cell geometry;
   - block and braille glyph tables;
   - text rasterizing;
   - animated text accessibility;
   - chart scales.
3. **Verify, rebuilt as modules.** It serves pages over localhost and renders shaders on SwiftShader. It adds checks for:
   - destroy restoring the host;
   - probe children;
   - axe-core;
   - scripted interactions and controlled echo;
   - the palette set four ways;
   - GPU context loss and fallback;
   - real image and camera inputs.
4. **Fences,** in ESLint and in doubled tests:
   - one owner each for events, WebGL2, and palette reads;
   - no color literals;
   - the tightened import rule;
   - meta and wrapper agreement.
5. **The 27 existing components migrated** onto the helpers and the palette.
6. **Two new references:** `mesh-gradient` (a shader) and `button` (a control).
7. **The site:** json, textarea, and palette controls, an event log, and demo state.
8. **Wave 3.** Seventeen builders and one vgpu spike:

   | Category | Components |
   |---|---|
   | shaders | shader-flow, aurora |
   | immersive | globe |
   | data | bar-chart, line-chart, donut-chart, kanban-board |
   | motion | marquee |
   | sections | hero, bento-grid, pricing, testimonials, stats-kpi |
   | ui | select, dialog, tabs, popover-tooltip |

## Verification

The gate after each step:
- `npm run build:registry`;
- `npx vitest run`;
- `npx eslint .`;
- `npx tsc --noEmit`;
- `npm run verify` over every component, serially.

Beyond the gate:
- An install check in a fresh Next app for one section, one control, and one shader.
- The catalog site's own check.
