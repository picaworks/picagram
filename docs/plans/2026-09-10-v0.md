# Pica v0

Approved 2026-09-10.

## Goal

An ASCII-first component library for React and plain HTML/CSS/JS. Every component ships in both shapes from one source and is readable by coding agents. A lightweight catalog site with a Figma-like layout lets people browse, tune, and copy components.

## Scope, in order

1. **Technique components.** ASCII renderers, text-mode UI, dither and halftone effects, and generative patterns, built from open techniques and credited.
2. **Soft clone of 21st.dev, in a clean room.** Rish captures references, a spec agent describes them, and a build agent implements from the spec alone. See `docs/decisions/0003-clean-room-soft-clone.md`.
3. **Dribbble-inspired patterns and layouts,** through the same path.

Out of scope for v0: the personal taste graph and any capture app.

## Build

- **Contract:** one framework-free core, one React wrapper, one meta per component (`docs/architecture/contract.md`). The shared runtime lives in `lib/`.
- **Generated outputs:** the React file, the HTML file, a markdown twin, `llms.txt`, a shadcn registry item, and the site catalog (`docs/architecture/outputs.md`).
  - Registry items carry the single React file rather than a shared runtime dependency. That departs from the first draft of this plan; `docs/decisions/0002-one-core-two-shapes.md` records why.
- **Verification:** both shapes render in Chromium without errors and match each other; motion stops under reduced motion and runs otherwise; there are no long tasks; the host is labelled; the bundle fits the budget.
- **Review:** a contact sheet where each component is kept, revised with a note, or cut. Only kept components ship.

## Catalog waves

- **Wave 1, ASCII core (12):** ascii-image (the reference), ascii-video, ascii-text, ascii-reveal, ascii-noise-field, ascii-waves, ascii-pointer-ripple, ascii-solid, ascii-rain, ascii-loader, ascii-frame, ascii-sparkline.
- **Wave 2, text mode and dither (15), plus the first captured references:**
  - Text mode: ascii-morph, ascii-terminal, braille-canvas, block-image, figlet-banner, ascii-topo.
  - Dither and effects: dither-image, dither-gradient, halftone-image, halftone-css, pixel-sort, glitch, duotone and posterize, scanlines, grain-overlay.
- **Wave 3, patterns (13):** dot-grid, line-grid, hatch, ten-print, truchet, tessellation, wave-lines, mesh-gradient (CSS only), grainy-gradient, noise-texture, low-poly, flow-field, moire.

Where Paper Shaders already ships a shader version of an effect, Pica's version stays CSS or CPU and says so.

## The site

- Next.js with static export.
- **Layers** on the left: categories, the component list, search, and tags.
- **Canvas** in the center: a board of frames. Zoomed out, it shows captures. Focusing a frame loads the live HTML file in an iframe.
- **Inspector** on the right: controls generated from meta, React, HTML, Install, and LLM tabs, and copy buttons that bake in the current values.
