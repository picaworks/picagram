# ASCII, motion and immersive release

The local expansion adds 47 original components to the approved 200 component collection. Nineteen are ASCII components, comprising ten complete websites and layouts and nine reusable diagrams or tools. Twenty three are animated Effects. Five are immersive entry experiences with readable details and accessible linear navigation.

The baseline at 42321bd contains 11 ASCII, 14 Effects of which seven animate, and five Immersive. The target is 247 components, 30 ASCII, 37 Effects of which 30 animate, and ten Immersive. Text mode entries are counted separately. Static effects remain in the collection and do not count toward the animated target.

Each component carries wave 14 and release `ascii-motion-2026-10-04`. The earlier 36 keep `microsites-2026-10-04`. NEW marks exactly those two authored batches. Review batch offers latest, 36 microsites, or both batches. It composes with category, search and facets. Existing hash links and the first batch query remain valid.

No production publication, remote push, main merge, browser navigation, cookie changes or security header changes are part of this release.

## Acceptance

Every addition must pass the complete component verification gate, including generated React and standalone HTML parity, lifecycle restoration, palette changes, declared interactions, JSON props, empty content and category byte budgets. Desktop 1280, tablet 768 and phone 390 are captured on ink and paper. Animated additions must move in both shapes, remain still under reduced motion and pause, stop offscreen, render reproducible fixed frames and avoid tasks over 50 milliseconds in the observation window. Immersive entries need keyboard and touch selection, overview, detail, back and Escape without trapping navigation.

Integration includes lint, type checks, the test suite, registry and static production builds, catalog keyboard/filter/reload/empty reset tests, copy payload and registry import tests, regression of the approved release and composer. Captures and review evidence are saved outside the checkout. Native ChatGPT annotation compatibility can only be claimed after a test in that native interface.
