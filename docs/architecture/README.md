# Architecture

Read in this order. Each file is short and answers one question.

| File | Question it answers |
|---|---|
| `overview.md` | What are the layers, and how does a component get from source into someone's project? |
| `contract.md` | What is a component made of, and what must its core do? |
| `outputs.md` | What does the build write, where, and from what? |
| `site.md` | How does the catalog site browse the generated files, and how does its inspector drive a live frame? |

The single most important idea is that each component is written once. If you read one section, read "Files" in `contract.md`.
